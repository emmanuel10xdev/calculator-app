# 🧮 Responsive Calculator App

A sleek, beautiful, and fully responsive calculator application designed to handle everyday mathematical operations with speed and precision. 


---

## ✨ Features

* **Core Arithmetic:** Supports standard addition, subtraction, multiplication, and division operations.
* **Responsive Layout:** Dynamically adapts to mobile, tablet, and desktop screens for a seamless experience.
* **Modern UI:** Built with a clean, distraction-free interface featuring smooth animations and hover states.
* **Keyboard Support:** Allows users to input numbers and operators directly via physical keyboards. *(Omit if not applicable)*


## 💡 What I Learned

Writing this project helped strengthen core development fundamentals, including:
* Implementing clean, maintainable logic for state and mathematical edge cases (like preventing division by zero).
* Creating fluid, mobile-first responsive layouts without sacrificing desktop usability.
* Managing DOM manipulation and event listeners efficiently.
